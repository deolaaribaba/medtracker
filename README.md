# MedTracker 🩺
> A practical web-based utility app built to ensure patients and care residents never run out of essential medication.

## 🎯 Why I Built This
As a Care Assistant with 3+ years experience in UK care, I saw first-hand how easily medication stock shortages can happen — with serious consequences. I built MedTracker to solve this real, daily problem using core web technologies.

## ✨ Features
- ✅ Track multiple residents/patients and their medications
- ✅ Auto-calculate remaining supply & alert when running low
- ✅ Clean, simple interface designed for busy care staff
- ✅ Dose schedule reminders & status display
- ✅ Runs in any browser — no extra software needed

## 🛠️ Built With
- HTML5 — Page structure & content
- CSS3 — Clean, responsive styling
- JavaScript — All app logic, calculations & alerts
- VS Code — Development environment
